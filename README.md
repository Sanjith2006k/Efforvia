# Efforvia

Efforvia is a full-stack MERN-based educational platform that helps students and professionals discover high-quality learning resources through a modern, personalized interface. Users can securely register, log in, search for any topic, and save structured learning paths for future learning.

## Features

* Secure JWT Authentication
* User Registration and Login
* Protected Dashboard
* Topic-Based Learning Search
* Curated YouTube Course Recommendations
* Learning Roadmaps
* Study Notes
* Save and Manage Learning Paths
* Modern Responsive UI
* Animated Backgrounds and Smooth Page Transitions

## Tech Stack

**Frontend**

* React

**Backend**

## Installation

### Clone Repository

```bash
git clone https://github.com/your-username/efforvia.git
cd efforvia
```

### Backend

```bash
cd server
npm install
npm run dev
```

Create a `.env` file:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
YOUTUBE_API_KEY=your_api_key
```

### Frontend

```bash
cd client
npm install
npm run dev
```

Create a `.env` file:

```env
VITE_API_URL=http://localhost:5000/api
```
